What's New

Every update brings new features, improvements, and fixes. Here's what we've been working on.

Version 1.2

August 2026

✨ Added

  • Remote Start — Start a camera device remotely from your monitor. No need to physically interact with the camera device.
  • Front / Back Camera Selection — Choose between front-facing and rear camera before starting. Ideal for different mounting positions.
  • Customizable Appearance & Themes — Customize app interface appearance with dynamic Material You color profiles and dark mode settings.
  • Remote Settings — Configure camera settings remotely from the monitor device, including alert sounds and motion detection.

🔧 Improved

  • Updated to latest Android SDK (targetSdk 35, compileSdk 36)
  • Improved overall stability and performance
  • Enhanced Koin dependency injection (4.0.2 → 4.x)

Version 1.1

February 2026

✨ Added

  • Custom Sound Picker — Select custom audio files for alerts from your device storage.
  • Alert Looping — Option to loop alert sounds continuously until dismissed.
  • Alert Duration — Configurable alert duration from 1 to 120 seconds.
  • Motion Zone Detection — Define specific screen areas for motion detection instead of monitoring the entire frame.
  • Web Interface — Access your camera stream from any browser on your local network.
  • Black Screen Mode — Stealth mode for covert monitoring. Turn off the camera device's screen while streaming continues.
  • Remote Alert Settings — Configure alert preferences from the monitor device.

🔧 Changed

  • Renamed "Siren" to "Alert" — more appropriate terminology throughout the app.
  • Updated CameraX 1.5.2 → 1.5.3
  • Updated Ktor 3.3.3 → 3.4.0
  • Updated Compose BOM 2025.12.00 → 2026.01.01
  • Migrated from Koin 3.5.6 to 4.0.2 with new API
  • Improved localization — added missing translations for all supported languages

🐛 Fixed

  • Motion detection zone bounds not persisting across app restarts
  • Audio permission flow on Android 13+
  • Black screen mode not syncing with monitor device

Version 1.0

December 2025

🚀 Initial Release

  • Real-time video streaming over WiFi
  • Audio streaming support
  • Motion detection with configurable sensitivity
  • Remote camera controls: zoom, torch/flash, photo capture, video recording
  • Device discovery via NSD (Network Service Discovery)
  • Material You theming with dynamic colors
  • Portrait and landscape orientation support
  • Settings persistence

🌐 Languages
